Privacy notice

How this private photo service uses information

{{ photographer.display_name }} decides why and how event photographs are used and is the customer-facing data fiduciary. OneNodeAI operates the OneNodeAI Studio service only as its technology processor under the studio’s written instructions.

Information and purpose

The service stores edited event photographs, private access records, and face vectors derived from faces already present in those photographs. This supports private gallery delivery and best-effort “find my photos” search; face similarity never grants access.

A reference photo is processed only for the requested search. Its upload, temporary face crop, and one-time search vector are discarded when processing finishes. Search result identifiers expire within one hour.

Authority and children

The studio confirms its authority for each event. A person uploading a reference photo must be the adult shown, have that adult’s permission, or have parent or guardian authority for a child shown.

Storage, access, and retention

Database and application processing occur in Singapore. Object storage uses Cloudflare R2 with an APAC placement hint, which is best effort and is not a country-residency guarantee. Private links, PINs, short sessions, tenant checks, and non-public object storage restrict access.

Normal event access lasts up to 365 days from first publication, followed by a 30-day deletion grace period. The studio retains its own edited source copy. A verified removal instruction unpublishes the entire affected event and targets cloud erasure within 24 hours; any replacement is a new event without the disputed photograph, so every old link and PIN remains invalid.
