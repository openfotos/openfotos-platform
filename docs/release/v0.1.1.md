# OneNodeAI Studio v0.1.1 supervised pilot

This is the first private, supervised Ballads of Love pilot built from the photographer UX revision:
one name-based event link (`/portfolio/events/<event-slug>/`) with a single four-digit PIN, uploads
accepted until publication, a consolidated desktop upload page, automatic verified face-model
download, automatic session resume with sign-out, and the redesigned portfolio, cover, gallery,
photo, and unlock pages. The desktop packages are unsigned: Windows SmartScreen and macOS Gatekeeper
will show an unverified-developer warning. Install only the artifact received through the studio's
approved GitHub release and verify it against `SHA256SUMS`.

Before publishing this draft release:

1. Verify every checksum from a separate machine.
2. Smoke-test on Windows x64 and Apple Silicon: one-time sign-in and automatic resume after restart,
   face-model auto-download state, event selection, sub-event selection, add photos, inline
   verification summary, single progress bar with stage text, pause/resume, submit, sign out, and
   diagnostics export.
3. Confirm the app contains `LICENSE`, `NOTICE`, `THIRD_PARTY_NOTICES.md`,
   `THIRD_PARTY_LICENSES.txt`, and both model-license files.
4. Confirm no model weights, photographs, credentials, or local checkpoint database are present.
5. Record both tester names, operating-system versions, artifact hashes, and results in the launch
   evidence log before manually publishing the pre-release.
