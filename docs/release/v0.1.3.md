# OneNodeAI Studio v0.1.3 supervised pilot

This is a desktop-only follow-up to v0.1.2 for the private, supervised Ballads of Love pilot. It
speeds up ingestion on the photographer's workstation: gallery previews/thumbnails now render in a
small worker pool, face embeddings run on a pool of single-threaded YuNet/SFace engines instead of
one photo at a time, and upload, rendering, and face indexing overlap so one photo's processing
starts as soon as its original is verified while later originals still transfer. No server,
storage, contract, or model changes: checksums, idempotency, retry/reset, and publication gates
behave exactly as before.

Both sides must still be updated together. The desktop checkpoint migrates itself on first launch.
The server requires migration `events.0015` (unchanged from v0.1.2), so if v0.1.2 is already
deployed, no migration run is needed before deploying the web service.

The desktop packages are unsigned: Windows SmartScreen and macOS Gatekeeper will show an
unverified-developer warning. Install only the artifact received through the studio's approved
GitHub release and verify it against `SHA256SUMS`.

Before publishing this draft release:

1. Run the migration service and confirm `events.0015` applied before the web service restarts
   (skip if v0.1.2 is already deployed).
2. Verify every checksum from a separate machine.
3. Smoke-test on Windows x64 and Apple Silicon: one-time sign-in and automatic resume after
   restart, workstation-label prefill, face-model auto-download state, event selection, sub-event
   selection, add photos, inline verification summary, single progress bar with stage text,
   pause/resume, submit, sign out, and diagnostics export.
4. Confirm the app contains `LICENSE`, `NOTICE`, `THIRD_PARTY_NOTICES.md`,
   `THIRD_PARTY_LICENSES.txt`, and both model-license files.
5. Confirm no model weights, photographs, credentials, or local checkpoint database are present.
6. Record both tester names, operating-system versions, artifact hashes, and results in the launch
   evidence log before manually publishing the pre-release.
