# OpenFotos v0.1.0 supervised pilot

This is the first private, supervised Ballads of Love pilot. The desktop packages are unsigned:
Windows SmartScreen and macOS Gatekeeper will show an unverified-developer warning. Install only
the artifact received through the studio's approved GitHub release and verify it against
`SHA256SUMS`.

Before publishing this draft release:

1. Verify every checksum from a separate machine.
2. Smoke-test login, model download, event refresh, a small upload, pause/resume, and diagnostics on
   Windows x64 and Apple Silicon.
3. Confirm the app contains `LICENSE`, `NOTICE`, `THIRD_PARTY_NOTICES.md`,
   `THIRD_PARTY_LICENSES.txt`, and both model-license files.
4. Confirm no model weights, photographs, credentials, or local checkpoint database are present.
5. Record both tester names, operating-system versions, artifact hashes, and results in the launch
   evidence log before manually publishing the pre-release.
